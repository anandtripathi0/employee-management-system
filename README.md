How to Run the Program:
1. Clone or download the project to your local machine.
2. Open a terminal in the project directory.
3. Compile the program:
g++ main.cpp -o employeeApp
4. Run the compiled program:
./employeeApp
Make sure you have a C++ compiler installed (like g++).
Features:
1. Add Employee:
- Prompts the user to input: Employee ID, Name, Salary, Department.
- Stores the employee data in memory.
2. View Employees:
- Lists all employees along with ID, Name, Salary, Department
